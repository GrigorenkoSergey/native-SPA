Кастомизация

У каждого компонента есть свои исходные стили, написанные разработчиком. Они хранятся в виде строке в статическом свойстве CustomCalendar.defaultStyles В каждом инстансе элемента есть свойство styles которое можно переписать полностью, либо дополнить по необходимости. Содержимое должно быть инстансом DOM Node. Т.е. ничего не мешает поместить туда целую таблицу стилей или добавить тег style. В случае вставки нескольких тегов style (например, дефолтных, и дополнительных) нужно использовать DocumentFragment.
